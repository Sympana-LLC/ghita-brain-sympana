# GHIȚĂ Brain Sympana

Installable memory pack for GHIȚĂ OS.

GHIȚĂ is a local agent operating system in the same family as Codex, Claude Code, OpenClaw, and Hermes Agent. The OS is already built. This pack is the **shared brain** anyone can plug in:

- Codex wrap contracts (how GHIȚĂ trains the harness, it does not replace it)
- Conductor pointers for voice-agent work
- Knowledge *references* (Hormozi, call-log corpora, and similar) without shipping private data

## Install

1. Install GHIȚĂ OS (`ghita-brain`).
2. Open **Settings → Connections**.
3. Connect ChatGPT / Codex, Claude Code, and Grok with a key or CLI login.
4. Under **GHIȚĂ Brain memory**, connect this repository:
   `https://github.com/Sympana-LLC/ghita-brain-sympana`
5. GHIȚĂ also creates **local memory** on that computer (`HOT.md`, `NOTES.md`). Your facts stay yours.

Anyone can replicate this. Keys never leave the installing machine. The pack is public references, not an account.

## What is not in this repo

- API keys
- Private call recordings or transcripts
- Personal HOT.md from a specific operator

Those stay on the host. `references/` tells GHIȚĂ they exist and how to ask for them.
