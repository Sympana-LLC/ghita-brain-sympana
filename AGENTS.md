# Agent instructions

## README maintenance (required for agents)

Read the root README before making changes. Keep a root `README.md` present and accurate. For every task, check whether the README needs an update; update it in the same change whenever setup, commands, configuration, environment-variable names, behavior, APIs, integrations, dependencies, deployment, troubleshooting, or limitations change. Preserve useful existing documentation and link to detailed docs rather than duplicating them.

Document only verified behavior and commands. Never include credentials, tokens, private customer data, or host-only runtime data. Do not invent setup instructions or claim untested behavior works. If something is unknown, state the gap clearly.

Before finishing, verify the README against the changed implementation and report what documentation was updated. If no README update is needed, explain why in the completion summary or pull request. A task with a required documentation update is incomplete until that update is included. Follow the repository's existing validation and release rules.
